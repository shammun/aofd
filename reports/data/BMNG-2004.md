# BMNG-2004 — NASA Blue Marble: Next Generation, September 2004, 5400 × 2700 (movie ch00_cross_product_why, globes)

- **Route**: HTTPS through `fluidpy.data.fetch` (`fluidpy.data.nasa_bmng.fetch_image`).
  - **New host**: NASA moved the Visible Earth files to
    `https://assets.science.nasa.gov/content/dam/science/esd/eo/images/bmng/` in 2025. Visible Earth pages now
    301-redirect to science.nasa.gov, and the old `eoimages.gsfc.nasa.gov` file URLs still answer 200.
  - `bmng-topography/september/world.topo.200409.3x5400x2700.jpg`: 1,720,074 B, 2.5 s, sha256 `5f5d16b1…6d09`.
    Land with relief shading and a flat dark ocean; best under wind arrows.
  - `bmng-topography-bathymetry/september/world.topo.bathy.200409.3x5400x2700.jpg`: 2,402,871 B, 2.0 s, sha256
    `4c6723e7…d3b`. Adds sea-floor shading.
  - **Sizes**: 8192 × 4096 is not published. The next size is 21600 × 10800 (per month, JPEG/GeoTIFF), which can be
    fetched and resized if the 3-D close-ups need it.
  - September was chosen because it matches Ian's month. The image is a cloud-free composite.
- **Licence verdict**: NASA imagery is not copyrighted in the US (NASA Images and Media Usage Guidelines,
  https://www.nasa.gov/nasa-brand-center/images-and-media/). Educational use needs no permission; acknowledge NASA,
  imply no endorsement, use no insignia. **Redistributable: yes (public domain in practice), with the credit.**
  Citation: Stöckli et al. (2005), NASA Earth Observatory.
- **Products**: identical copies (no processing) in `movies/ch00/ch00_cross_product_why/data/real/`
  (`globe_bmng_topo_200409_5400x2700.jpg`, `globe_bmng_topo_bathy_200409_5400x2700.jpg`) and in G: `derived/ch00/`.
- **Orientation check**: `outputs/ch00/data/p5_globe_overlay.png`. NE 50m coastlines drawn over the image line up
  everywhere: column 0 = 180°W, row 0 = 90°N, equirectangular. For three.js `SphereGeometry` with the default UVs,
  u = 0 maps to longitude 180°W, so check the seam offset in the scene.
- **Credit line**: "Blue Marble: Next Generation, NASA Earth Observatory (Reto Stöckli, NASA GSFC)."
